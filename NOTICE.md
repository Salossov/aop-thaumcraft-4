# Происхождение

Thaumcraft 4 создан Azanor. Исходные текстуры, звуки, переводы и другие ресурсы в локальном проекте извлечены из `Thaumcraft-1.7.10-4.2.3.5.jar`. Оригинальный JAR сохранён без изменений. Перенос не заявляет авторство этих материалов и не меняет условия их использования.

Проект предназначен для личного использования. Условия оригинального Thaumcraft сохраняются. Автор порта — [Salossov](https://github.com/Salossov); оригинальный мод — [Azanor](https://www.curseforge.com/minecraft/mc-mods/thaumcraft).

Сборочный каркас основан на официальном NeoForge MDK 1.21.1, commit `7819b902a351b03fe71db00754d103b5a31c4ebf`. Лицензия шаблона сохранена в `TEMPLATE_LICENSE.txt`. NeoForge, Curios, Java и Gradle сохраняют собственные условия и лицензии.

Нормализацию поглощения особой брони в `thaumcraft.api.SpecialArmorProperties` адаптирую из `ISpecialArmor.ArmorProperties` Minecraft Forge 1.7.10. Сохраняю исходное указание Minecraft Forge Public License v1.0 и ссылку на первичный исходник: https://github.com/MinecraftForge/MinecraftForge/blob/1.7.10/src/main/java/net/minecraftforge/common/ISpecialArmor.java . Условия шаблона не заменяют условия этого фрагмента.
