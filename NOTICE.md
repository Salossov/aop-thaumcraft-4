# Происхождение

Thaumcraft 4 создан Azanor. Исходные текстуры, звуки, переводы и другие ресурсы в этом локальном проекте извлечены из предоставленного пользователем `Thaumcraft-1.7.10-4.2.3.5.jar`. Оригинальный JAR сохранён без изменений. Перенос не заявляет авторство этих материалов и не меняет условия их использования.

Проект предназначен для личного использования. Условия оригинального Thaumcraft сохраняются.

Сборочный каркас основан на официальном NeoForge MDK 1.21.1, commit `7819b902a351b03fe71db00754d103b5a31c4ebf`. Лицензия шаблона сохранена в `TEMPLATE_LICENSE.txt`. NeoForge, Curios, Java и Gradle сохраняют собственные условия и лицензии.
