# Manual gameplay checklist

This list includes additional manual cases. Version 0.7.3 was also checked in actual JEI 19.64.0.455 and EMI 1.1.24 clients at GUI scales 1-4, including aspect tooltips, filled JEI variants and research navigation; this does not claim every case below was played through. Use a separate test instance/world and normal tick speed. Core and server need 1.0.0; add the example only when testing addon content.

1. Load an existing player save. Compare completed research, aspect pools, wand parts, focus upgrades and stored vis before/after updating. Reconnect to a server and change dimensions.
2. With only the core, open all six legacy tabs, ordinary research text, native diagrams and grouped recipe pages at every book window/zoom setting. Existing progress and layouts should remain available.
3. Add the example: its Workshop tab appears, the introduction unlocks after Thaumonomicon basics. Check flowed text, the positioned image, item/aspect tooltips, links, the native recipe and the Java meter page at original, square and full-window sizes.
4. Change the example mixed-page text/position JSON through a datapack and run /reload on a server with two clients. Both should receive the update. Break JSON syntax, a parent, a page link and a page type in separate trials: reload must fail while the previous working book and progress remain usable. Restore valid files and reload again.
5. /give yourself thaumcraft_example:rod, cap, focus and device. Assemble the addon rod/cap in the normal diagonal wand recipe. Check research gates, exact vis cost, held/inventory models and attached head alignment. Upgrade the focus in the focal manipulator. Start, hold, release, change held item, die and disconnect during use. Check centivis, cooldown and end callbacks; failed application must not charge.
6. Fill the example relay with essentia through phials/tubes. Verify capacity 64 and single-aspect behavior. Put it in range of an energized node/relay: charge should rise only when vis is available, to at most 1000 centivis. Unload/reload its chunk and save/reopen the world; no duplication, forced loading or lost stored contents.
7. Test four configurations in separate launches: no viewer, JEI 19.64.0.455, EMI 1.1.24+1.21.1, both. Core must work without the integration JAR too. With both viewers, each TC4 category/recipe should appear once through EMI.
8. Inspect each of the seven recipe categories. Compare native craft/ritual outcomes with the preview; check central items, dynamic runic/enchantment variants, amount tooltips, centivis conversion, instability, experience, research requirements, probabilistic infernal notes and catalysts. Search uses of a custom aspect and of a primal vis ingredient.
9. Defaults: unresearched recipes are listed with their requirements; unscanned item aspect compositions are hidden. Scan an item and learn a research without reconnecting; filters should update. Switch settings to RESEARCHED_ONLY and ALL respectively, then reverse them. Try /reload with addon recipes added/removed.
10. With a Thaumonomicon in inventory, click a research link from a viewer. Known research should open directly; locked research should center its category without unlocking. Remove the book and confirm the server rejects opening the menu.
11. Use + in the arcane workbench: one set, maximum sets, overlapping/tag ingredients, component-bearing stacks, nonempty grid, full inventory, missing ingredients, missing research, absent/empty wand, closed or different menu, stale request. Ingredients may move but no vis/output should be created/spent. On failure compare every inventory/grid stack and component. Repeat on a dedicated server. Normal subsequent crafting must retain the original cost/research checks.
12. Remove the example, reload the world, then restore it in the test instance. Retained knowledge keys must not be reset. Do not use this as a save-recovery procedure for arbitrary missing-mod block data.

Build/linkage tests do not validate rendered pixels, viewer discovery, menu interactions or dedicated-server runtime behavior. Record the exact configuration and log if any case fails.

13. With viewers 0.7.3, open every recipe category in JEI: the left workstation list must contain each device once, including after moving between many recipes. Check native arcane/crucible/infusion artwork, grouped ingredient quantities, research status and parent tooltips in both viewers.
14. On a fresh player, the aspect sidebar and index show six named primals and `?` for compounds. Unknown tooltips must not reveal names, components or sources. Discover a compound, spend its points to zero, then inspect it again: it stays visible. Vis/essentia lookup should use one aspect entry.
15. Scan one source item, inspect its known aspects: hover shows that item and its yield, full source pages show only scanned items/block items. Scan a second source and discover another aspect without reconnecting: names and recipe/usage results update without duplicate pages. Unscanned sources must remain absent even with composition ALL. Reconnect, change worlds and /reload; filters must follow the current player/catalog.
