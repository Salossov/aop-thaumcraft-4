# AOP: Thaumcraft 4

[Русский](README.ru.md)

I am porting Thaumcraft 4.2.3.5 to Minecraft 1.21.1 / NeoForge. Development is in progress.

> **Personal use only.** Thaumcraft and all of its assets belong to Azanor. This repository contains the original mod's logic and assets and is not intended for redistribution.

[Thaumcraft 3: Reforged](https://github.com/notlikethiss/thaumcraft-3-reforged) inspired this project.

## Building

JDK 21. Dependency versions are defined in `gradle.properties`.

```powershell
./gradlew.ps1 assemble
```
